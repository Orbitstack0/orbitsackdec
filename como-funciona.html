Primeiro, o essencial

Antes de tudo: o que é um consórcio?

Consórcio é um sistema de aquisição planejada em grupo.

Pessoas com objetivos semelhantes participam de um grupo e contribuem periodicamente.

Os recursos formam um fundo utilizado para possibilitar contemplações ao longo do plano, seguindo as regras estabelecidas para aquele grupo.

06

Existem dois caminhos principais para a contemplação.

Sorteio: os participantes elegíveis concorrem conforme as regras previstas para o grupo.

Lance: o participante pode ofertar um valor para disputar uma contemplação conforme as regras e disponibilidade do grupo.

Aprofundando

Sorteio ou lance: qual é a diferença?

Sorteio

  • Segue os critérios previstos para o grupo
  • Ocorre nas assembleias
  • Não exige uma oferta adicional de lance
  • Participação depende das condições aplicáveis à cota

Lance

  • É uma oferta realizada pelo participante
  • Pode aumentar a possibilidade de antecipar a contemplação
  • Regras e modalidades variam conforme o grupo
  • A oferta segue as condições previstas para o grupo.
A contemplação por lance segue os critérios e as regras estabelecidos para cada grupo.

  • Lance livre

    O participante define a oferta conforme as regras do grupo.

  • Lance fixo

    A oferta segue um percentual ou condição previamente definida.

  • Lance embutido

    Quando permitido, parte do próprio crédito pode ser utilizada na composição do lance, reduzindo o valor líquido disponível para aquisição.

As modalidades disponíveis dependem do contrato e das regras de cada grupo.

É comum confundir lance com entrada de financiamento, mas são conceitos diferentes. No consórcio, o lance é uma oferta utilizada para disputar a contemplação. Ele pode representar antecipação de valores do próprio plano, conforme as regras e modalidade de lance aplicáveis. Não é simplesmente uma "entrada" usada para liberar imediatamente a compra do bem.
